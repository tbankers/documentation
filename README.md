# Таск-трекер

Веб-приложение для управления задачами внутри небольшой команды.

Пользователи смогут регистрироваться, создавать доски проектов, добавлять колонки и карточки, перетаскивать карточки мышью и назначать ответственных. Совместная работа — через приглашения на доску.

## Основные требования

- Работает в браузере без установки.
- Сервер выдерживает нагрузку школьной команды.
- Данные сохраняются после перезапуска сервера.
- Пользователь видит только те доски, куда его добавили.

## Ключевые технические решения

### 1. Хранение данных

База данных на **PostgreSQL**.

### 2. Сервер на Go

| Библиотека | Назначение |
| ---------- | ---------- |
| `chi`      | Лёгкий и понятный роутер. |
| `pgx`      | Быстрый пул соединений и безопасные запросы. |
| `bcrypt`   | Хеширование паролей. |
| `JWT`      | Токены, которые проверяются в middleware. |

Сервер не хранит сессии — каждый запрос содержит всё необходимое. Это упрощает масштабирование.

### 3. Аутентификация и доступ

- При регистрации и входе выдаётся JWT-токен с ограниченным временем жизни.
- Middleware проверяет токен во всех защищённых маршрутах.
- Дополнительно проверяется, имеет ли пользователь доступ к конкретной доске (владелец или участник).

### 4. Клиентская часть

Чистый HTML, CSS и JavaScript. Для перетаскивания карточек — **SortableJS**.

В будущем можно заменить фронтенд на React/Vue, не меняя API.

### 5. API и взаимодействие

- **REST API**: клиент отправляет fetch-запросы, сервер отвечает.
- Нет WebSocket — все операции инициируются клиентом.

### 6. Миграции базы данных

Используем **golang-migrate** + SQL-файлы в репозитории.

## Схема взаимодействия и стек

### Поток данных

```
Клиент
  │  HTTP (с JWT в заголовке)
  ▼
Go-сервер (проверка токена, бизнес-логика)
  │
  ▼
PostgreSQL
  │  JSON-ответ
  ▼
Клиент
```

### Компоненты и инструменты

- **Бэкенд:** Go, chi, pgx, golang-jwt, bcrypt
- **База данных:** PostgreSQL, golang-migrate
- **Контейнеризация:** Docker (здесь запускаются Go и PostgreSQL)
- **Прочее:** Git/GitHub, Makefile

### Инфраструктура и развёртывание

- **Локально:** PostgreSQL в Docker, Go-сервер запускается из командной строки.
- **Конфигурация:** настройки (пароль БД, секретный ключ) — в `.env`.
- **Демо-хостинг:** Render, Railway или Fly.io.
- **Сборка:** Go-сервер собирается из исходников при пуше в GitHub. PostgreSQL — как встроенный сервис или Neon.
- **Деплой:** автоматический деплой настраивается штатными средствами облачной платформы.

В результате получится удобный инструмент для управления рабочими задачами.
